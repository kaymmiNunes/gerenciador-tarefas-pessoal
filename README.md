## Up List - Gerenciador de tarefas pessoal
>O <strong>Up list </strong> é uma plataforma inteligente de produtividade projetada para simplificar a organização diária. Ele permite que os usuários gerenciem suas rotinas, definam prioridades e acompanhem metas, tranformando listas de afazeres em ações concretas para otimizar o tempo e reduzir o estresse. 

## Status: Concluído

## ⚙️ Funcionalidades

- [x] Cadastro de tarefas
- [x] Listagem de tarefas 
- [x] Marcação de tarefa com cuncluída
- [x] Exclusão de tarefa
- [x] Edição de tarefas
- [x] Separação entre tarefas pendentes e concluídas 
- [x] Filtro por prioridade ou categoria
- [x] Campo para data ou prazo
- [x] Área com resumo das tarefas

 ## 🚀 Como executar?
 
 ## Pré-requisitos
 Antes de começar, certifique-se de ter instalado em sua máquina:
 
 - Node.js: Versão 18 ou superior.
 - Git: Para clonar o repositório

## Execução 
Siga os passos abaixo para rodar o projeto:

1- Clone o repositório:

```bash
  Git clone https://github.com/kaymmiNunes/gerenciador-tarefas-pessoal.git
```

2- Acesse a pasta do projeto:
```bash
- cd gerenciador-tarefas-pessoal
```
